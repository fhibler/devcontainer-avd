# avd Feature 1.0.0

An isolated Arista AVD controller with runtime, tools, and editable source modes
for Debian, Ubuntu, and RHEL-family containers on Linux amd64 and arm64.

**This Dev Container Feature is not officially supported by Arista Networks.**
Please open issues in this [GitHub repository](https://github.com/fhibler/devcontainer-avd/issues).

Add `ghcr.io/fhibler/devcontainer-avd/avd:1` to your Dev Container's `features`.
See the [usage guide and complete option reference](https://github.com/fhibler/devcontainer-avd/blob/main/README.md)
for configuration examples and defaults.

Detailed documentation covers [configuration](https://github.com/fhibler/devcontainer-avd/blob/main/docs/configuration.md),
[source development](https://github.com/fhibler/devcontainer-avd/blob/main/docs/source-development.md),
and [Ansible integration](https://github.com/fhibler/devcontainer-avd/blob/main/docs/ansible.md).
